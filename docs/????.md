# TrafficBar 使用说明

本文是 TrafficBar 的完整使用手册，适用于当前 **Windows 10 x64** 自用版本。程序是便携式绿色软件，不写系统服务、不注入 Explorer、不安装驱动。

## 1. 系统要求

- Windows 10 x64（Windows 11 只做了基础兼容，未完整验证）
- 管理员权限（程序清单为 `requireAdministrator`）
- 建议安装 Visual Studio 2022 + Windows SDK 10.0.19041 仅用于自行编译
- NVIDIA 显卡温度需要安装 NVIDIA 驱动，且系统存在 `nvml.dll`
- CPU 温度和硬盘 SMART 需要主板/硬盘提供对应的 WMI/ACPI 数据

## 2. 安装与升级

### 安装

1. 解压发布包到固定目录，例如 `G:\tools\TrafficBar`。
2. 双击 `TrafficBar.exe`。
3. 在 UAC 提示中允许运行。
4. 程序启动后会在任务栏通知区域左侧显示监控文字。

程序目录会生成：

```text
TrafficBar.exe
TrafficBar.ini              配置
TrafficBar_history.dat      历史流量
TrafficBar.log              启动/退出/锁定诊断日志
plugins\                    可选插件
```

### 升级

1. 先退出正在运行的 TrafficBar。
2. 替换 `TrafficBar.exe`。
3. 保留原来的 `TrafficBar.ini` 和 `TrafficBar_history.dat`。

升级不会主动删除配置或历史。不要把个人配置和历史文件放进发布包。

### 卸载

1. 右键菜单选择“退出”。
2. 如果启用了开机自启，在菜单中关闭“开机自启”，或删除计划任务：

```bat
schtasks /Delete /TN TrafficBar /F
```

3. 删除程序目录。需要保留历史时，先备份 `TrafficBar.ini` 和 `TrafficBar_history.dat`。

## 3. 任务栏显示

程序默认贴在主任务栏通知区域左侧：

- 横向任务栏：两行紧凑布局，上传/下载、CPU、内存和主指标。
- 左侧/右侧竖向任务栏：自动切换为窄条纵向布局。
- 多显示器：自动发现副任务栏并创建独立显示窗口，支持悬停和右键菜单。
- DPI/主题：跟随任务栏高度、DPI 和深浅色主题。

如果任务栏在左侧或右侧，宽度较窄时会自动拆行显示。

## 4. 鼠标与快捷键

- 鼠标移到任务栏文字上约 300 ms：显示悬停浮帖。
- 双击任务栏文字：打开任务管理器。
- 右键任务栏文字或托盘图标：打开菜单。
- `Ctrl+Alt+S`：打开隐藏的“自定义指标”设置窗口。
- `Ctrl+Alt+M`：备用快捷键（当 `Ctrl+Alt+S` 被占用时）。

## 5. 右键菜单

菜单包含：

- 显示 CPU
- 显示内存
- 显示 GPU（悬停）
- 显示磁盘（悬停）
- 外观主题：跟随任务栏 / 深色 / 浅色 / 深蓝 / 墨绿
- 网卡：自动选择或指定网卡
- 刷新间隔：0.5 / 1 / 2 / 5 秒
- 开机自启（任务计划）
- 流量统计...
- 进程流量...
- 关于 / 退出

## 6. 悬停浮帖

悬停浮帖显示：

- 实时上传 / 下载速度
- CPU 使用率，以及可用时的 CPU 温度
- 已用内存 / 物理内存总量 / 百分比
- 可选系统盘占用，以及可用时的 SMART 健康状态和温度
- 可选 GPU 使用率，以及 NVIDIA 显卡温度
- 自定义指标（股票等）
- 插件指标

当自定义指标超过 3 个时，浮帖只显示 3 行，使用鼠标滚轮或浮帖内部细滚动条查看其余项目。

浮帖背景会跟随任务栏主题；点击桌面不会再把浮帖误判为全屏应用而隐藏（0.15.0 起）。

## 7. 配置说明

配置文件为程序目录下的 `TrafficBar.ini`。常用配置：

```ini
[general]
show_cpu=1
show_memory=1
show_disk=0
show_gpu=0
theme_mode=0
interval_ms=1000
font_size=9
adapter_luid=0000000000000000

[custom]
enabled=1
primary=AAPL
items=AAPL=usAAPL;MSFT=usMSFT;TX=hk00700
refresh_ms=5000
show_percent=0
```

### `[general]`

| 键 | 说明 |
|---|---|
| `show_cpu` | 是否在悬停中显示 CPU |
| `show_memory` | 是否显示内存 |
| `show_disk` | 是否显示系统盘占用和 SMART |
| `show_gpu` | 是否显示 GPU 使用率/温度 |
| `theme_mode` | `0` 跟随任务栏，`1` 深色，`2` 浅色，`3` 深蓝，`4` 墨绿 |
| `interval_ms` | 采样间隔，单位毫秒 |
| `font_size` | 字号 |
| `adapter_luid` | 指定网卡 LUID；`0` 表示自动选择 |

### `[custom]`

| 键 | 说明 |
|---|---|
| `enabled` | 是否启用量化/自定义指标 |
| `primary` | 任务栏第二行显示的主指标名称 |
| `items` | 分号分隔的 `名称=代码` 列表 |
| `refresh_ms` | 行情刷新间隔 |
| `show_percent` | 是否显示涨跌幅百分号 |

代码支持：

- `sh` / `sz` / `bj` / `hk` / `us` 前缀
- 6 位 A 股代码
- 5 位港股代码
- 美股 ticker

删除 `TrafficBar.ini` 可恢复默认配置。

## 8. 历史流量

右键菜单打开“流量统计...”：

- 按日 / 按月 / 按年查看
- 显示今日、本月、今年和总计
- 数据仅保存在本机
- 支持清空历史（会确认）

历史文件为 `TrafficBar_history.dat`，格式为文本：

```text
TrafficBarHistory 1
2026-11-12 7498265 33545046
```

每行是 `日期 上传字节 下载字节`。程序每 60 秒、打开统计窗口、退出和系统关机时保存，并保留 `.bak` 备份。

> 只统计 TrafficBar 运行期间产生的流量；程序关闭期间不计入。

## 9. 进程流量

右键菜单打开“进程流量...”：

- 使用 Windows ETW 的 `Microsoft-Windows-Kernel-Network`
- 统计 TCP / UDP 发送和接收字节
- 显示进程名、PID、实时上传/下载速率和累计流量
- 统计从本次打开进程流量窗口/程序运行期间开始

该功能需要管理员权限。首次打开窗口时才启动 ETW，不再在程序启动时长期运行。

## 10. 开机自启

推荐使用任务计划，不使用旧式 HKCU Run：

1. 右键菜单勾选“开机自启（任务计划）”。
2. 程序会创建名为 `TrafficBar` 的计划任务，触发器为当前用户登录时，运行级别为最高可用权限。
3. 旧版本的 HKCU Run 项会自动迁移为任务计划，避免 UAC 阻止启动。

检查任务：

```bat
schtasks /Query /TN TrafficBar
```

手动测试：

```bat
schtasks /Run /TN TrafficBar
```

如果自启无效：

- 确认任务存在且已启用；
- 确认任务“作为用户运行”是当前账户；
- 检查“任务计划程序”历史记录；
- 查看 `TrafficBar.log` 是否有启动记录；
- 不要只保留 HKCU Run 项，因为它无法可靠启动管理员程序。

## 11. 安全模式与诊断

遇到系统卡死、锁屏异常或怀疑某个监控功能时，使用安全模式启动：

```bat
TrafficBar.exe --safe-mode
```

安全模式会跳过：

- 插件
- ETW 进程流量
- GPU 使用率/温度
- CPU WMI 温度
- SMART 查询

保留：

- 网速
- CPU 占用
- 内存
- 磁盘占用
- 行情

程序在以下时机写入 `TrafficBar.log`：

- 启动
- 启动完成
- 会话锁定/解锁
- 退出
- 每分钟心跳

锁屏后程序会暂停采样和置顶守护，解锁后恢复。

## 12. 主题与皮肤预设

右键菜单“外观主题”提供：

- 跟随任务栏
- 深色
- 浅色
- 深蓝
- 墨绿

当前是预设皮肤，不支持任意颜色取色器。

## 13. GPU、CPU 温度和 SMART 的可用性

- **CPU 温度**：通过 `MSAcpi_ThermalZoneTemperature` 查询；不同主板可能没有数据。
- **GPU 温度**：动态加载 NVIDIA `nvml.dll`，只支持 NVIDIA；AMD/Intel 暂不支持。
- **GPU 使用率**：通过 PDH `GPU Engine` 计数器。
- **SMART**：通过 `MSStorageDriver_FailurePredictStatus` 和 `MSStorageDriver_ATAPISmartData` 查询；部分 NVMe/USB 硬盘不支持。

如果某项不可用，悬浮窗会自动隐藏该项，不会弹错误框。

## 14. 插件

### 安装

1. 将 64 位 DLL 放入 `TrafficBar.exe` 同目录的 `plugins`。
2. 重启 TrafficBar。
3. 悬停浮帖会追加插件指标，最多 4 项。

### 接口

```cpp
struct TrafficBarPluginMetric {
    wchar_t label[32];
    wchar_t value[64];
};

extern "C" __declspec(dllexport) int __cdecl
TrafficBarPluginGetMetrics(TrafficBarPluginMetric* metrics, int capacity);
```

返回写入的指标数量。接口头文件：`plugins/api/TrafficBarPlugin.h`。示例源码：`plugins/samples/demo.cpp`。

插件是本地 DLL，没有沙箱、签名或超时保护，只应加载可信插件。

## 15. 常见问题

### 监控文字不见了

- 确认任务栏仍显示；
- 点击任务栏或通知区域折叠按钮；
- 检查是否被全屏应用遮挡；
- 0.15.0 起点击桌面不会再误隐藏；旧版本请升级。

### 开机没有自动启动

- 用 `schtasks /Query /TN TrafficBar` 检查任务；
- 确认任务没有被禁用；
- 确认没有只留下 HKCU Run 项；
- 查看 `TrafficBar.log`。

### 进程流量为空

- 需要管理员权限；
- 需要打开“进程流量”窗口；
- 某些 VPN/虚拟网卡流量可能不归属可见进程；
- 尝试切换网络或重新打开窗口。

### 温度/SMART 不显示

- 对应硬件/驱动不支持；
- 确认程序以管理员运行；
- GPU 温度仅 NVIDIA；
- SMART 需要硬盘暴露 WMI 数据。

### 锁屏后系统卡死

TrafficBar 已加入锁屏暂停采样、ETW 延迟启动和安全模式。若仍出现：

1. 用 `--safe-mode` 启动；
2. 记录 `TrafficBar.log` 最后几行；
3. 检查 Windows 事件查看器中的 `Kernel-Power 41`、WHEA、显卡和磁盘错误；
4. 更新显卡/芯片组/BIOS 驱动，并排查电源和内存。

系统级卡死通常需要结合系统事件日志和硬件诊断，不能只凭单个应用判断。

## 17. 已知限制

- 完整适配以 Windows 10 为准，Windows 11 仅做基础 fallback。
- CPU 温度、SMART 取决于硬件和 WMI 支持。
- GPU 温度仅 NVIDIA。
- 自定义皮肤目前只是预设，不支持任意颜色。
- 插件无沙箱。
- 历史/进程统计只覆盖程序运行期间。
